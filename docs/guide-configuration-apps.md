## Configuration par Application

### TickTick

1. Ouvrir l'onglet **Habits**
2. Créer 8 habitudes avec les noms ci-dessus
3. Pour chaque habitude :
   - **Rappel** : configurer l'heure correspondante
   - **Notes** : coller la description + le "Pourquoi"
   - **Fréquence** : Tous les jours
   - **Tags** : matin / midi / soir
4. Créer une tâche récurrente **"Validation hebdo"** chaque dimanche à 20h
5. Dans la tâche de validation, créer une checklist avec les critères de la semaine en cours

### Habitica

1. Créer 8 **Dailies** (pas Habits ni To-Dos)
2. Difficulté recommandée :
   - **Facile** : Image, Environnement, Sommeil
   - **Moyen** : Corps, Business
   - **Difficile** : Identité, Anti-école, Mental
3. Pour chaque Daily :
   - Ajouter le "Pourquoi" dans les **Notes**
   - Créer des **Checklists** pour les sous-actions
   - Exemple Corps : ☐ 10 squats ☐ 5 pompes ☐ 20s gainage
4. Configurer les **rappels push** aux 4 horaires
5. Créer un tag "Validation S1", "Validation S2", etc.

### Loop Habit Tracker (Android)

1. Créer 8 habitudes de type **Oui/Non**
2. Fréquence : **Tous les jours**
3. Rappels individuels :
   - Anti-école → 07:30
   - Identité, Corps, Image → 08:00
   - Business, Environnement → 12:00
   - Mental, Sommeil → 20:00
4. Description : coller le texte complet (description + source + pourquoi)
5. Utiliser les **graphiques intégrés** pour suivre la progression
6. Export CSV possible pour analyse dans un tableur

### Track & Graph

1. Créer 8 **Trackers** de type booléen (Oui/Non)
2. Graphiques à configurer :
   - **Ligne temporelle** : progression globale sur 28 jours
   - **Barres** : 8 items par jour
   - **Camembert** : répartition matin/midi/soir
3. Rappels aux 4 horaires
4. Créer un tracker séparé pour la validation hebdomadaire

### HabitNow

1. Créer 8 habitudes avec catégories :
   - Matin : Identité, Corps, Image, Anti-école
   - Midi : Business, Environnement
   - Soir : Mental, Sommeil
2. Configurer les rappels par catégorie
3. Activer le widget pour l'écran d'accueil
4. Utiliser les statistiques intégrées

## Validation Hebdomadaire

### Semaine 1 — Fondations
- [ ] 7 actions business réalisées
- [ ] 7 actions corps réalisées
- [ ] 7 phrases identité écrites

### Semaine 2 — Consolidation
- [ ] Posture maintenue 7 jours
- [ ] 1 conversation business initiée
- [ ] Règle des 3 secondes appliquée 3 fois

### Semaine 3 — Expansion
- [ ] 1 reset utilisé avec succès
- [ ] 7 alignements réalisés
- [ ] 1 apprentissage business noté

### Semaine 4 — Intégration
- [ ] 8/10 critères cochés
- [ ] 1 témoignage écrit
- [ ] 1 résultat business concret

## Solution de Rattrapage

| Situation | Action |
|-----------|--------|
| 1 jour raté | Version minimale : 10 squats + 5 pompes + 20s gainage + 1 action business |
| 3 jours ratés | 1 action/jour pendant 3 jours, puis retour à la normale |
| 7 jours ratés | Recommencer semaine 1, version allégée (4 items/jour) |

16. **Brené Brown** — Daring Greatly (vulnérabilité et courage)
